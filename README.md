# Bardak Coffee — Ana Website

Bardak Coffee için tek sayfalık tanıtım sitesi. QR menü sisteminden (bardakcoffee-menu reposu) ayrı, bağımsız bir proje.

## İçerik
- Hero (tanıtım)
- Hakkımızda
- Menü tanıtımı (QR menü sitesine link verir: brdkmenu.netlify.app)
- Galeri
- Çalışma saatleri, konum (Google Maps embed), iletişim

## Görseller
Şu an telifsiz (Unsplash lisanslı) stok görseller kullanılıyor. Gerçek Bardak Coffee fotoğrafları elde edildiğinde `index.html` içindeki `<img>` ve arkaplan `background` linkleri değiştirilerek kolayca güncellenebilir.

## Netlify kurulumu
1. Bu repoyu Netlify'a bağlayın (Build command boş, Publish directory: `.`)
2. Site adını istediğiniz gibi ayarlayın (örn. bardakcoffee-anasayfa)
